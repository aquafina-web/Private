#Private attribute

A private attribute is a variable inside a class which is meant to be accessed only within that class, not outside it.
(It's usually written with a double underscore: __)
I made this project because using private attributes help to protect data and control how it gets accessed or changed.

From this project I learned : Data protection, Encapsulation, etc.
